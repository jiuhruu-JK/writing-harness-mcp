## 判据

对照 spec 与用户对话，逐条核对实现：

- 用户要求与实现一致且完整 → 判过。
- 接口 `run(payload: dict) -> dict` 与 spec 里写的入参键、返回键不一致 → 打回。
- 出现用户没要求的功能 → 打回。
- 出现替用户揣摩或下定义的实现 → 打回。
- 出现与用户工作流相矛盾的实现 → 打回。
- 用户要求未实现 → 打回。

实现细节的判断以 spec 与 `AGENTS.md` 的「应当遵循的项目结构」「开发纪律」为准，不自行新增要求。用户要求的事项所必然包含的基础操作，属于审查范围内的正常实现。
